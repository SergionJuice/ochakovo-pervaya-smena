# Иллюстрации игры

Созданы через imagegen для текущей версии. Исходные PNG сохранены, WebP-версии используются на сайте. Рита — вымышленный персонаж. Логотип не генерировался и взят из архива компании.

Единое направление: яркая рисованная 2D-игра с выразительными тёмно-синими контурами, кремовым светом, красными трубами/элементами, бирюзовой техникой, крупными читаемыми формами. Без надписей и интерактивных элементов внутри фоновых изображений: функциональные предметы созданы отдельными SVG.

- factory.png — вертикальный рисованный цех с ёмкостями, красными трубами, окнами и конвейером на переднем плане; без людей и бутылок.
- laboratory.png — вертикальная лаборатория с сиреневыми шкафами, приборами заднего плана и свободным бирюзовым столом для игровых предметов.
- warehouse.png — вертикальный склад с охристыми стеллажами, коробками, погрузочными воротами и свободным передним планом для собираемого заказа.
- mentor.png — прозрачная горизонтальная полоса из трёх равных ячеек: Рита машет, радуется с большим пальцем вверх, задумчиво помогает. Молодая взрослая наставница с кудрями, красной кепкой и комбинезоном.

Оптимизация PNG → WebP меняет формат и качество сжатия, не содержание иллюстраций.

## Версия 3: продукция и одежда Риты

Упаковки — единые SVG в `dist/art.js` (`bottle('kvass')`, `bottle('mojito')`), используются во всех сценах и заказах. Точный текст брендов задан кодом, а не сгенерирован внутри растра. Референсы просмотрены на официальных страницах:
- https://nonalco.ochakovo.ru/brand/ochakovskij/
- https://nonalco.ochakovo.ru/brand/moxito-osvezhayushhij-3/

`mentor-ppe.png` создан через встроенный imagegen как редактирование `mentor.png`. Используемый WebP: `dist/assets/game/mentor-ppe.webp`. Содержание задания: сохранить ту же взрослую Риту, лицо, пропорции и три равных состояния (приветствие, успех, помощь); заменить одежду на белый лабораторный халат, защитные очки и сеточку для волос, сохранить красный акцент; прозрачный фон; тот же рисованный стиль и тёмно-синие контуры. Одежда в игре иллюстративная, окончательный комплект СИЗ следует согласовать с предприятием.
