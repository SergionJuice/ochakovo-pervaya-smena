## Поведение

- Данные: `public/education.js`. Поиск по словам имени, города и сокращений; NFKC, нижний регистр, ё→е, нормализация пробелов и пунктуации.
- Запрос не уходит на сервер и не попадает в аналитику. Нет зависимости от API и состояний сетевой загрузки. Отключение сети не мешает подсказкам после загрузки страницы.
- Combobox по паттерну WAI-ARIA APG: https://www.w3.org/WAI/ARIA/apg/patterns/combobox/ ; `aria-expanded`, `aria-controls`, `aria-activedescendant`, listbox/option, live-region. Стрелки перемещают активную строку, Enter подтверждает, Escape/Tab закрывают без выбора.
- По закрытию первая строка не подставляется. Можно изменить текст, очистить поле, выбрать другой вариант либо перейти к ручному вводу. Набранный текст при переходе сохраняется. Невыбранный произвольный текст также принимается как ручное название: справочник не является барьером.
- Результаты содержат город и явное название филиала. В серверное/локальное поле `education` попадает одна строка с названием и городом, без нового обязательного поля.
- Список в потоке формы, высота ограничивается доступным visualViewport. Прокрутка и pointercancel не выбирают строку. Ручное действие не спрятано внутри прокручиваемого списка.
- Выбранное значение, произвольный запрос и ручной режим сохраняются вместе с черновиком. После успешного сохранения черновик очищается.
