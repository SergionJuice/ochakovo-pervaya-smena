# Первая смена: обновление 8 — 24.10.2026

## Изменения

- Реальный приём анкет в D1 и HR независимо от почты. Режим `cabinet` не вызывает почтовый сервис. Подтверждение «Заявка отправлена!» выводится только после сохранения сервером.
- Убран дополнительный ключ первого входа. HR/HR открывает только обязательную смену пароля; после неё первоначальный пароль перестаёт действовать. Существующие пароли не сбрасываются.
- Широкий кабинет для десктопа: таблица, поиск, фильтр направления, карточка, Excel всех / выборки / одной анкеты. Серверный экспорт защищён той же авторизацией, что и список.
- На старте уменьшены банки, на карте перерисован грузовик и скорректирована дорога, чтобы машина помещалась в видимой части. Механика розлива и склада сохранена.
- Компактные условия анкеты, явные телефон/email, полный текст согласия в раскрываемом блоке, обычные сообщения об отправке без технических надписей.

## Автоматические проверки

`npm test`: десять наборов проверок. Покрыты оба способа связи, календарные даты, сохранение черновика при ошибке, шесть порядков прохождения заданий и восстановление прогресса, серверная валидация, атомарная запись заявки, повтор без дубля, HR/HR, обязательная первая смена пароля, проверка текущего, отзыв сессий, ограничение входа, почтовый перехватчик без внешней отправки.

Новый `cabinet-v8.mjs` вызывает реальные обработчики POST заявки и GET Excel с изолированной SQLite/D1-обвязкой. Проверены сохранение без почтовых ключей и первоначальной настройки HR, отсутствие почтового вызова, неизменность ID при повторе, запрет экспорта без сессии / до смены пароля. 61 заявка с одинаковым временем корректно проходят пагинацию 50+11. Работают русский поиск и фильтр. Excel содержит все 61 либо одну выбранную заявку, 15 столбцов; значения не становятся формулами.

Сгенерированные книги прочитаны openpyxl: русские строки, номера, freeze A2, фильтр и текстовые типы корректны. `npx tsc --noEmit` прошёл. Производственная сборка запускается перед публикацией.

## Браузер и границы проверки

В управляемом Chrome проверены CSS-окна через iframe:

| Окно | Высота карты: содержимое / доступно | Кнопки |
| --- | --- | --- |
| 320×568 | 513 / 513 px | Все три, по 56 px |
| 390×844 | 781 / 781 px | Все три, по 56 px |
| 430×932 | 869 / 869 px | Все три, по 56 px |

При размере корневого текста 200% на 320×568 содержимое выросло до 907 px при доступных 513 px: появилась необходимая прокрутка, элементы не скрываются. Это проверка CSS-окон, а не физического Safari/Android с панелями браузера.

На десктопе 1363×936 проверены вход HR, широкий кабинет, таблица и карточка. Для визуальной проверки авторизованного интерфейса использовалась временная локальная страница с отдельной фикстурой; она удалена перед сборкой. Реальные анкеты не просматривались, вымышленные анкеты на рабочий сайт не подавались. Начальное изменение производственного пароля оставлено владельцу. Логика авторизации и смены проверена автоматическими тестами.

Кнопка скачивания на локальной фикстуре подготовила файл и показала соответствующее состояние. Перехват события загрузки облачным браузером завершился тайм-аутом: получение файла этим браузерным инструментом не подтверждено. Сам бинарный ответ настоящего серверного маршрута и открытие XLSX проверены отдельно.

Скриншоты: `screenshots-v8/`. Кабинет без анкет снят в локальной изолированной проверке оформления. Остальные — текущий интерфейс локальной сборки. Данные и ключи в скриншоты не включены.

## Эксплуатация

Производственное окружение: `APPLICATIONS_ENABLED=true`, `APPLICATION_DELIVERY=cabinet`, текст / версия согласия, существующий HR_PASSWORD_PEPPER. HR_BOOTSTRAP_KEY больше не используется. Почта выключена по запросу владельца. Заявки хранятся в D1 `applications`, связанная запись `mail_outbox.state=cabinet`. Анкеты не являются публичными и не сохраняются в исходный код.

Адрес без суффикса аккаунта Sites требует собственного домена и настройки DNS. Смена slug меняет только название сайта в начале текущего адреса.
